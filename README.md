# PIP Evidence Planner

A privacy-first mobile application that helps people securely organise evidence for Personal Independence Payment (PIP) claims, reviews and appeals.

## 🌐 Live Application

https://pip.risten.co.uk

---

## Key Features

- Secure Evidence Tracker
- Daily Symptom Diary
- Medication Log
- Appointment Tracker
- Medical Document Storage
- Timeline Generator
- PDF Report Export
- Offline First
- Encrypted Local Storage
- Biometric Authentication

---

## Privacy

Privacy is at the heart of this application.

- No advertising
- No tracking
- No cloud storage
- No user accounts
- No sale of personal data

All personal information remains securely stored on the user's device unless the user chooses to export it.
